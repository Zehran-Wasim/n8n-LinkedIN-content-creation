# AI LinkedIn Content Creator using n8n

An AI-powered LinkedIn content generation workflow built with n8n, Tavily AI research, Gemini/OpenRouter models, and Google Sheets.

## Features
- AI-generated LinkedIn posts
- Automated topic research
- Trending content discovery
- Structured post generation
- Google Sheets content storage
- AI writing assistance
- Content idea generation

## Tech Stack
- n8n
- Tavily AI
- OpenRouter
- Google Gemini
- Google Sheets
- Docker

## Workflow Architecture
1. User enters content topic
2. Tavily researches topic online
3. AI Agent analyzes research
4. AI generates LinkedIn content
5. Structured post created
6. Output stored in Google Sheets

## Main Nodes Used
- Manual Trigger
- Form Input
- Tavily Search
- AI Agent
- OpenRouter Chat Model
- Google Sheets
- Set Node
